## Summary

This README describes the use of the training scripts for protein-peptide LRs.

## Preliminaries

### Conda environment

The training scripts are written in Python. They use packages installed in a
conda environment. The main package installed in the environment is pandas.

The environment has already been created in `conda/env` and the script used to
create it was `make-env.sh`, for reference. It does not need to be run again.

---

The following describe the data that will be required as
inputs, and configurations for training.

### Genome data

Training requires as one set of inputs the outputs from the PrePPI `run_elm`
pipeline for a genome. The outputs from the pipeline contain the match, ELM
class conservation and disorder data located in the set of `ProtPeptide_ELM`
files in the collection of `Motifs` directories for each protein.

The "shares/databases/hfpd/genomes/<genome_name>" directory is used as the
"hfpd_project_home" for training.

### Training data

Training requires as its second set of inputs the uniprot ids for the genome
("target_uniprot_ids"), the TP set ("high_confidence_set"), and the set of
uniprot ids that are not part of the TP set but are also excluded from the TN
set, ("exclusion_set").

So, the final TN set will be all pairs of "target_uniprot_ids", excluding pairs
in the "high_confidence_set" and "exclusion_set".

### ELM classes

The set of ELM classes to calculate LRs for should be provided
("target_elm_classes").

## Running the scripts

1. Prepare the `config.json` configuration file. The "scratch_dir" will be the
directory where the final output will be stored, along with other intermediate
and log files generated by the script.

2. Run the `driver.sh` script. This is done to distribute the processing tasks
as an array job on the hpc. This is done because originally, a single
node did not have sufficient memory for all of the processing.

The array job will take less than 5 minutes. They can be identified by the name
"prp_main" using `squeue`

3. Open `reducer.sh` and make sure the `chdir` directory in the script matches
the "scratch_dir" being used to store the intermediate files and outputs.

4. Run `sbatch < reducer.sh`. This produces the final output by aggregating
counts from the intermediate files, computing probabilities and
the target likelihood ratios.

This will take less than 5 minutes.

If everything is successful, there will be a `motif_elm.lr` file produced in
"scratch_dir" directory.
